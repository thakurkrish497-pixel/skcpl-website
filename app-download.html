help_outline Quick Installation Guide

1 Windows PC Installation

  1. Click the Download for Windows button above.
  2. Extract the downloaded SKCPL-Windows-x64.zip folder.
  3. Open the folder and double-click SKCPL.exe.
  4. Tip: Right-click SKCPL.exe → Pin to Start or Pin to Taskbar for one-click access.

2 Apple Mac Installation

  1. Click the Download for Apple Mac button above.
  2. Double-click the downloaded SKCPL-macOS.zip file to extract it.
  3. Drag SKCPL - Connect to Waves.app into your Applications folder.
  4. Launch from Spotlight Search or Launchpad.
